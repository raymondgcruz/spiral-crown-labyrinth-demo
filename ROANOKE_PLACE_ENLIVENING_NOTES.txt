ROANOKE PLACE ENLIVENING PASS

Purpose:
- Preserve Restore Place as a beautiful simulated sanctuary when no ZIP field exists.
- When the user generates a ROANOKE Local Field from the Field tab, Restore Place now upgrades into an enlivened local field using the active ZIP snapshot.

Implemented:
- Restore Place accepts activeField and renders live local cards when available.
- ZIP geocoding now resolves actual ZIP centroids instead of fixed placeholder coordinates.
- Air Quality uses Open-Meteo Air Quality API: US AQI, PM2.5, PM10, UV index.
- Weather/environment uses Open-Meteo current/daily data plus weather.gov when available.
- Field snapshots now include metrics: Air Vitality, Celestial Rhythm, Radiance, Moisture, Weather.
- Field snapshots now include placeSignals from Overpass/OSM for local parks, libraries, water, and community signals.
- Restore Place displays actual local signals and unlocks local pilgrimage tasks when a field is active.
- Labyrinth screen is eagerly imported to reduce mobile wait time when selecting the Labyrinth tab.
- Restore/Map/Codex chunks warm-load after initial paint with a shorter delay.

Known limitation:
- Photos are category-relevant sanctuary images, not verified photographs of the exact ZIP locale. Exact local imagery would need a photo/search backend or API key and should not be embedded into a static GitHub Pages frontend without careful privacy and quota controls.
