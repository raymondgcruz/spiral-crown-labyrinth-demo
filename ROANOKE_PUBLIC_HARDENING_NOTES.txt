ROANOKE PUBLIC HARDENING MODE

Purpose:
Protect the deployed browser artifact without making the living source difficult to edit.

Commands:
  npm run build:public
  npm run deploy:public

Public hardening behavior:
- Disables sourcemaps.
- Strips console/debugger statements from the production browser bundle.
- Prevents GEMINI_API_KEY from being embedded into hardened deploy builds.
- Uses anonymous hashed asset names for hardened builds.
- Avoids readable dynamic chunk names in public deploy.
- Audits dist/deploy_me for source maps, source files, env files, obvious secrets, console calls, debugger statements, and source path leakage.
- Writes deploy_me/ROANOKE_PUBLIC_SEAL.json containing file hashes and hardening claims.

Lawful boundary:
- Source remains readable and editable.
- Deploy becomes a sealed public artifact.
- No frontend hardening can make browser code impossible to inspect.
- Truly secret logic should eventually live behind a backend/API, not in GitHub Pages.

All paths.
